# LeadIQ

> B2B sales-intelligence and contact-data platform. LeadIQ exposes three programmable surfaces over one data core: a public GraphQL Data API at https://api.leadiq.com/graphql (people search, company search, advanced grouped/flat search, prospect lists, account usage, data feedback, champion tracking), a REST Prospector API at https://prospector.leadiq.com for saved lists and prospects, and a remote MCP connector at https://mcp.leadiq.com/mcp exposing seventeen tools to AI agents over OAuth 2.0. Metering is credit-based (Universal Credits): 0.1 UC per profile, 1 UC per verified work email, 10 UC per direct phone, 3 UC per company. Generated by API Evangelist from LeadIQ's published surfaces; LeadIQ serves no llms.txt of its own (probed 2026-08-13, HTTP 404 on leadiq.com and developer.leadiq.com).

## APIs

- [GraphQL Data API](https://api.leadiq.com/graphql): Single GraphQL endpoint. HTTP Basic auth with the Secret Base64 key sent verbatim. Anonymous introspection is enabled — 216 types, 18 Query fields, 11 Mutation fields.
- [Prospector REST API](https://prospector.leadiq.com): OpenAPI 3.1.0, 14 operations under /v1 for lists, prospects, email verification, Salesforce export and caller identity. Auth via X-API-Key (the DECODED key) or a bearer JWT.
- [MCP connector](https://mcp.leadiq.com/mcp): Streamable HTTP, OAuth 2.0 with dynamic client registration, scopes `leadiq:api` and `offline_access`. Seventeen tools plus a guided `icp` prompt.

## MCP tools

- EnrichPeople — known people by LinkedIn URL, work email, or name + company; batch up to 10. Wraps `searchPeople`.
- EnrichCompanies — known companies by domain, name, or LinkedIn; batch up to 10. Wraps `searchCompany`.
- FindPeople — ICP prospecting, paginated. Wraps `flatAdvancedSearch`.
- FindCompanies — ICP account discovery with contact counts. Wraps `groupedAdvancedSearch`.
- FindJobChanges — recent job changes and promotions with previous/current position.
- BrowseProspectLists / CreateProspectList / GetProspectList — list management. Free.
- AddProspectToList / AttachProspectToList / CreateProspect / GetProspect / SearchProspects — prospect management. Free.
- VerifyEmail / VerifyProspectEmail — deliverability checks. 0.1 UC each.
- ExportProspectToSalesforce — export a saved prospect as a Lead or Contact with duplicate detection.
- CheckCredits — balance, live unlock costs, signed-in account. Free.

## Operational notes for agents

- GraphQL errors arrive in the `errors` array with HTTP **200**. Never treat 200 as success on api.leadiq.com/graphql.
- No rate-limit response headers exist on any surface. The published limit is 60 requests/minute (Standard); exhaustion returns 429 with no Retry-After.
- Field selection is the billing contract on GraphQL — over-selecting `phones` costs 10 UC per person.
- Four of five write paths are documented as NOT idempotent, including the Salesforce export, which writes irreversibly into the caller's CRM and has no delete path. There is no Idempotency-Key mechanism.
- Advanced search: `skip + limit` may not exceed 10,000; use the opaque `after` cursor for anything larger.
- Sustained API access is sales-gated — all plans get 50 one-off test calls; beyond that requires an enterprise agreement.
